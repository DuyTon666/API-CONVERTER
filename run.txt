resolve

Điền resolution cho một entry trong report. Chỉ sửa report, không ghi catalog.

Decision hợp lệ:

reassign
keep_existing
approve_new
repair_existing

Approve mã mới:

npm run errors:resolve -- \
  --module <module> \
  --code <code> \
  --decision approve_new \
  --approved-by "<name>"

Ví dụ:

npm run errors:resolve -- \
  --module admin \
  --code 5405 \
  --decision approve_new \
  --approved-by "ren"

Giữ mã cũ:

npm run errors:resolve -- \
  --module admin \
  --code 5405 \
  --decision keep_existing \
  --approved-by "ren"

Repair existing:

npm run errors:resolve -- \
  --module admin \
  --code 5405 \
  --decision repair_existing \
  --approved-by "ren"

Reassign sang mã mới:

npm run errors:resolve -- \
  --module admin \
  --code 5405 \
  --decision reassign \
  --new-code 5416 \
  --approved-by "ren"

Nếu một code xuất hiện nhiều entry, chọn đúng source file:

npm run errors:resolve -- \
  --module admin \
  --code 5405 \
  --decision approve_new \
  --approved-by "ren" \
  --source-file "API_provider_update.docx"

Dùng report riêng:

npm run errors:resolve -- \
  --module admin \
  --code 5405 \
  --decision approve_new \
  --approved-by "ren" \
  --report 3.build/reports/error_codes_review.json

Raw command:

python3 2.pipeline/run_api_import.py resolve \
  --module admin \
  --code 5405 \
  --decision approve_new \
  --approved-by "ren"
